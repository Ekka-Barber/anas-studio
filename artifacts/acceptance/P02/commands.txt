Findings handled on the way (docs/book-preview.md, "Two pdf.js findings")
- Joined Arabic: through browser font faces Chrome drew Word's already-joined glyphs as unjoined letters; the reader sets disableFontFace, and pdf.js draws glyph outlines, identical to the PDF.
- Text order: pdf.js reverses lam-alef ligatures («اإلهداء»); fixLigatures restores them against pypdf's text in the selectable layer, and screen readers get pypdf's text per page (the pdf.js layer is aria-hidden). The reference applies only to a PDF with the preview's page count.
- page-flip's autoSize sized the book by width alone and overflowed the screen; the box sets the height (autoSize off).
- A leaf page-flip hides measures 0 wide, so pages are drawn at the book's page width; a turning page is never blank.
