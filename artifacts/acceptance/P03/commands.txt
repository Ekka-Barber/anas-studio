## Orchestrator audit, 2026-09-25
Defects found in the orchestrator's own files and fixed:
1. service_role had no grants on staff/audit_events (the CLI no longer auto-exposes new
   tables), so the staff-admin Edge Function could not read or write them. Fixed with
   least-privilege grants (staff select/insert/update; audit_events insert only).
2. supabase/config.toml [auth.email] enable_signup=false disabled the whole email provider
   ("Email logins are disabled"), so no sign-in code could be sent. Re-enabled; sign-ups
   stay off through [auth] enable_signup=false. Proven: unknown email with create_user
   false -> 422 otp_disabled; with create_user true -> 422 signup_disabled; /signup ->
   422 signup_disabled.
Worker-code findings fixed by the orchestrator:
3. Every admin page overflowed at 360 px: the admin layout loaded tokens.css but not the
   site base (globals.css: fonts, box-sizing reset, body margin, focus). Now loads
   globals.css; the team table scrolls inside .tableWrap.
4. auth.spec expected the step-up dialog right after TOTP enrolment, when the TOTP is still
   fresh and the invite correctly succeeds without it. The spec now signs out and back in
   with an email code (aal1) so the dialog path is exercised.
5. vitest --mode db runs files serially (fileParallelism false): the last-owner test
   deactivates other owners in the shared database.
