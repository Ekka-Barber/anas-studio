# P08 round tooling

The orchestrator runs every P08 round with these files (D45 roles; `PLANS/P08-KICKOFF.md`, "How to run").

- `p08-round.js`: the round workflow. One `sonnet-worker` (Sonnet 5.5, effort max) builds; one `auditor` (Opus 5.5, effort xhigh) audits the diff; at most two fix passes, each by a fresh worker. Findings the auditor marks `orchestrator: true` (outside the round's files, or a contract ruling) end the loop with `needs_orchestrator`. Run it with the Workflow tool: `Workflow({ scriptPath: '<absolute path of this file>', args: <the round's JSON> })`. The JSON is `{ round, title, readFirst[], brief, files[], checks[], auditFocus }`, passed inline as the whole object. The briefs of rounds 10b to 11c are kept as they ran; `round-12a.json` (the journeys) and `round-12b.json` (the documents) are next. Auditors run at effort max since round 10b.
- `round-report.cjs`: after the workflow, `node artifacts/acceptance/P08/tools/round-report.cjs <the workflow's journal.jsonl> artifacts/acceptance/P08/rounds/round-NN.md "<title>"` writes the worker reports and the audits into the round file; the orchestrator then appends its rulings and its own checks.

Before a round: hold `.anasaq-execution.lock` (created with `fs.openSync(path, 'wx')`), add the round's exact files to its `allowedPaths`, and check that no other writer is running. After it: rule on every finding, read every migration, money path, token path and file path yourself, re-run the checks from a fresh `pnpm db:reset` with `pnpm db:import` and `pnpm db:demo-catalog` (and the edge runtime restarted: `docker restart supabase_edge_runtime_ANASAQ.ME`), use every changed control in the browser at 360 and 1440 for a UI round, commit by explicit path, fast-forward `main` and push.
