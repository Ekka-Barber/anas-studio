## Guard proof: `pnpm test:db` refuses a database that is not local

  Run against the configured environment, whose DATABASE_URL is a hosted
  endpoint. A non-zero exit with no test executed is the correct outcome.

  HOST  pnpm test:db                     exit=1

  HOST  TEST_ENV=local pnpm test:db      exit=1
        Error: Refusing to run database tests: DATABASE_URL does not point at a
        local PostgreSQL host.

  The guard runs in `vitest.config.ts` before a single test file is collected, so
  no test can bypass it, and the refusal never prints the URL, which carries
  credentials.
