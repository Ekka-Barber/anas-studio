ANASAQ final targeted evidence, retrieved 2026-09-21

1. Cloudflare, "Payload on Workers: a full-fledged CMS, running entirely on Cloudflare's stack", published 2025-09-30.
URL: https://blog.cloudflare.com/payload-cms-workers/
Finding: Payload ran through the Next.js OpenNext adapter. Cloudflare first connected the official Payload Postgres adapter; node-postgres worked on Workers. The article sets pool maxUses:1, then puts Hyperdrive in front for connection pooling and query caching. It separately demonstrates native R2 binding storage. This is evidence of feasibility, not proof that ANASAQ's Supabase pooler, schema, migrations, admin bundle or Free-plan CPU limits pass.

2. Payload deployment documentation.
URL: https://payloadcms.com/docs/production/deployment
Finding: Payload runs inside Next.js and may be self-hosted where Next.js runs. A database, persistent storage and email remain separate requirements. An ephemeral filesystem requires a cloud storage adapter.

3. Payload storage adapters documentation.
URL: https://payloadcms.com/docs/upload/storage-adapters
Finding: @payloadcms/storage-r2 is specifically for Cloudflare Workers and a native R2 bucket binding. @payloadcms/storage-s3 is the S3-compatible alternative. R2 buckets are private by default. ANASAQ selects storage-r2 and keeps originals/private files private.

4. Payload jobs and versions documentation.
URLs: https://payloadcms.com/docs/jobs-queue/overview ; https://payloadcms.com/docs/versions/drafts
Finding: jobs persist in the database; configured schedules do nothing unless a runner executes them. Native drafts inject _status; schedulePublish supports future publish/unpublish. The Worker scheduled handler must run Payload jobs. It is not a second deployment.

5. Payload authentication documentation.
URLs: https://payloadcms.com/docs/authentication/overview ; https://payloadcms.com/docs/authentication/operations ; https://payloadcms.com/docs/authentication/custom-strategies
Finding: native auth documents HTTP-only cookies, JWTs, sessions, reset, verification, lockout, API keys and custom strategies. Searches of these current pages found no MFA, two-factor or TOTP facility. Absence in these pages is not an eternal product guarantee, so P03 checks the installed version before adding OTPAuth.

6. Payload discussion #16937, "Alternatives to Sharp image optimization on Cloudflare Workers?"
URL: https://github.com/payloadcms/payload/discussions/16937
Finding: discussion states Payload imageSizes is hard-wired to Sharp and Sharp is unavailable on Workers; proposed workarounds use original R2 objects plus Cloudflare Images. Community discussion is lower authority than product docs. It supports the no-Sharp spike and does not prove any workaround safe or free.

7. Cloudflare Workers pricing.
URL: https://developers.cloudflare.com/workers/platform/pricing/
Finding: Free includes 100,000 requests/day and 10 ms CPU/invocation at retrieval; Paid starts at USD 5/month. The limits make runtime measurement in P00 mandatory. Prices and quotas can change.

8. Cloudflare R2 pricing.
URL: https://developers.cloudflare.com/r2/pricing/
Finding: Free allocation exists and internet egress is free. Storage and Class A/B operations are metered after included usage. This is suitable for synthetic development, not a promise of zero-cost production.

9. Cloudflare Web Analytics and GraphQL Analytics API.
URLs: https://developers.cloudflare.com/web-analytics/ ; https://developers.cloudflare.com/analytics/graphql-api/
Finding: Web Analytics is available on all plans. GraphQL Analytics API requires a scoped Cloudflare API token and exposes account/zone datasets with filtering, pagination, rate limits and sampling. Official tutorial https://developers.cloudflare.com/analytics/graphql-api/tutorials/end-customer-analytics/ documents `httpRequestsAdaptiveGroups`, `sum.visits`, `dimensions.clientRequestPath`, `clientRequestHTTPHost` and `requestSource: "eyeball"` on that selected dataset. Migration guide https://developers.cloudflare.com/analytics/graphql-api/migration-guides/graphql-api-analytics/ identifies this adaptive node as replacement for deprecated fixed-granularity nodes and exposes `avg.sampleInterval`. It does not by itself prove ANASAQ's account entitlement, exact schema or an HTML content-type filter. P06 must introspect the actual account and prove required fields/filters. If `sampleInterval > 1`, required HTML/status filtering is unavailable, or data is missing/delayed/unauthorized, exact visit and page KPIs are unavailable. A path grouped by request count is only "most requested public pages" after filtering, never unique page views; assets/admin/API/health must be excluded. Never turn missing into zero or sampled estimates into exact values.

10. Cloudflare Next.js guide.
URL: https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/
Finding: current guide recommends vinext for most new Next.js apps but labels vinext beta and retains OpenNext for existing apps with compatibility gaps. Payload's official 2025 Workers work used OpenNext. P00 decides by executing the exact Payload routes; documentation alone is insufficient.

11. Payload Postgres and transaction documentation.
URLs: https://payloadcms.com/docs/database/postgres ; https://payloadcms.com/docs/database/transactions
Finding: official Postgres adapter uses node-postgres/Drizzle and supports transactions. Adapter schemaName is experimental in current docs. Checked-in migrations, exact generated table names and direct transaction tests are mandatory.

12. Resend, Turnstile and Supabase evidence already captured.
URLs: https://resend.com/pricing ; https://resend.com/docs/dashboard/emails/idempotency-keys ; https://developers.cloudflare.com/turnstile/plans/ ; https://supabase.com/pricing ; https://supabase.com/docs/guides/platform/backups
Finding: free development allocations exist. Resend documents idempotency keys. Turnstile has a Free plan. Supabase Free may pause and does not provide the production backup guarantees selected for launch; production cost approval remains a gate.

13. Sentry pricing.
URL: https://sentry.io/pricing/
Finding: Developer is free, one user, unlimited projects and 5,000 errors at retrieval. ANASAQ sends scrubbed error metadata only, with no replay, request bodies, payment payloads, email/address or tokens. Quotas can change.

14. UptimeRobot pricing.
URL: https://uptimerobot.com/pricing/
Finding: Free is USD 0, 50 monitors and a five-minute interval at retrieval. Configure one external HTTPS health monitor. It is external availability evidence, not application correctness or an SLA.

15. Registry, repository and security metadata.
URLs: https://registry.npmjs.org/ ; https://api.github.com/ ; https://api.osv.dev/v1/querybatch
Finding: exact pins, licenses, unpacked sizes and activity are in final-package-snapshot.json. OSV returned no known advisories for the queried exact direct-package versions on 2026-09-21. It did not audit a lockfile or every transitive dependency.
